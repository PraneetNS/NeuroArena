# NeuroArena Asset Licenses & Attributions

All terrain textures and assets in NeuroArena are released under **Creative Commons Zero (CC0 1.0 Universal / Public Domain Dedication)**, complying with open-source and local-only standards.

## Terrain Textures (KTX 2.0 Format)

The terrain textures are procedural CC0 stylized painterly surfaces inspired by Poly Haven and ambientCG PBR materials, compressed into Khronos KTX 2.0 (`.ktx2`) GPU containers:

| Asset Name | Description | Source / Format | License |
| :--- | :--- | :--- | :--- |
| `grass_diffuse.ktx2` | Stylized painterly emerald grass albedo | Poly Haven / ambientCG inspired, KTX2 | CC0 Public Domain |
| `grass_normal.ktx2` | High-frequency grass blade normal map | Procedural tangent normal, KTX2 | CC0 Public Domain |
| `dirt_diffuse.ktx2` | Warm terracotta / loam soil albedo | ambientCG inspired, KTX2 | CC0 Public Domain |
| `dirt_normal.ktx2` | Compacted soil & pebble normal map | Procedural tangent normal, KTX2 | CC0 Public Domain |
| `rock_diffuse.ktx2` | Stratified sandstone & granite cliff albedo | Poly Haven inspired, KTX2 | CC0 Public Domain |
| `rock_normal.ktx2` | Sedimentary cliff strata normal map | Procedural tangent normal, KTX2 | CC0 Public Domain |
| `sand_diffuse.ktx2` | Golden dune & beach sand albedo | ambientCG inspired, KTX2 | CC0 Public Domain |
| `sand_normal.ktx2` | Wind-swept dune ripple normal map | Procedural tangent normal, KTX2 | CC0 Public Domain |
